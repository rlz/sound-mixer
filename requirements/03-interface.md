# 03. Интерфейс

## Язык

- Английский — язык интерфейса по умолчанию, включая текст в окне, сообщения об ошибках и описания системных разрешений.
- HTML документа объявляет английский язык; язык разработки macOS приложения — английский.

## Иконки

- Для элементов React интерфейса используем бесплатные SVG иконки Font Awesome через официальный компонент `@fortawesome/react-fontawesome`. Импортируем только используемые иконки из пакетов `@fortawesome/free-*-svg-icons`, чтобы они входили в локальную сборку и работали без сети.
- Иконка дополняет текст действия или состояния. Если кнопка содержит только иконку, у нее есть доступное имя на английском; декоративные иконки скрыты от VoiceOver. Недоступность устройства и ошибки не обозначаются одной иконкой без текста.

## Окно

- Основное окно имеет две панели: слева список выходов и виртуальных шин, справа настройки микса выбранного элемента.
- В верхней части окна есть общий переключатель «Микширование включено/выключено» с однозначным текстовым состоянием. Он доступен независимо от выбранного элемента.
- Слева предусмотрены группы «Устройства вывода», «Виртуальные шины» и «Маршруты BlackHole». Все реальные выходы видимы независимо от наличия настроенного микса.
- У каждой строки слева есть название, индикатор доступности и ползунок общей громкости. Выбранная строка различима без опоры только на цвет.
- Сохраненный, но отсутствующий выход остается в группе устройств вывода после перезапуска. Его можно выбрать, просмотреть микс и удалить сохраненную настройку. Перед удалением показываем, что будут удалены строки этого микса; само устройство macOS не удаляется.
- Кнопка добавления позволяет создать внутреннюю шину или маршрут BlackHole. Имя виртуального элемента редактируется на месте или в его настройках.
- Правая панель показывает имя выбранного элемента, его тип, список источников микса, ползунок каждого источника и действие добавления источника.
- При добавлении источника каталог разделен на устройства ввода, приложения и внутренние шины. Недоступные элементы имеют пояснение причины.
- Уже добавленный вход остается строкой микса при отсутствии устройства, включая отсутствие при запуске. Его можно удалить из микса. Создание новой строки для отсутствующего устройства не предлагается.
- Для моно источника доступен выбор «Левый», «Правый», «Стерео»; для стерео источника этот выбор не показывается.

## Состояния и обратная связь

- Пустой микс объясняет, как добавить источник.
- Отказ в разрешении на микрофон или системное аудио отображается рядом с соответствующим источником и содержит действие для открытия системных настроек.
- Отсутствие BlackHole и отсутствие свободных каналов объясняются до создания маршрута.
- Сохраненный маршрут BlackHole виден при отсутствии драйвера или нужного экземпляра и доступен для удаления. Для отсутствующих устройств показываем последнее известное имя, если оно сохранено, и UID в подробностях; иначе показываем UID как название. Текст статуса прямо сообщает, что устройство не подключено.
- Ошибка валидации маршрута показывает затронутые элементы и не меняет активный аудиограф.
- Изменения уровней и названий отображаются после успешного подтверждения от Swift. При ошибке UI возвращает подтвержденное значение и показывает причину.
- В выключенном состоянии ползунки и состав миксов остаются видимыми и редактируемыми; интерфейс сообщает, что звук через Sound Mixer сейчас не выводится.
- Снимок состояния из Swift объединяет сохраненные элементы и обнаруженные устройства, передает отдельно доступность и причину остановки каждого маршрута. После подключения или удаления отсутствующего устройства интерфейс обновляется по подтвержденному снимку без перезапуска окна.

## Доступность

- Все действия доступны с клавиатуры; для ползунков есть текстовые подписи и числовое значение.
- Учитываются системные размер текста, контрастность и темная тема macOS.
- Состояние устройства и ошибка передаются текстом, а не только значком или цветом.
