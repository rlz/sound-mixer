# 01. Устройства и виртуальные шины

## Реальные выходы

- Левая панель перечисляет все доступные устройства Core Audio с выходными каналами, независимо от того, выбраны ли они системным выходом.
- Для каждого элемента показываются имя системы, тип, состояние доступности и ползунок общей громкости его микса от 0 до 100 %.
- Список обновляется при подключении, отключении и изменении свойств устройств без перезапуска приложения.
- Устройство узнается по UID Core Audio. При временном исчезновении настройки остаются, элемент помечается недоступным; после возврата с тем же UID они восстанавливаются.
- Установленное устройство BlackHole остается видимым среди устройств Core Audio. Созданные маршруты BlackHole показываются отдельно и ссылаются на него; интерфейс различает их, чтобы избежать путаницы.

## Внутренние виртуальные шины

- Пользователь может создать, переименовать и удалить шину. Имя не пустое после удаления пробелов по краям; одинаковые имена допускаются, так как идентификатором служит UUID.
- Шина имеет свой микс, общую громкость и может служить источником другого микса.
- Шина не появляется в настройках звука macOS и не может быть выбрана сторонним приложением как устройство вывода. Это явно указано в интерфейсе создания.
- При удалении шины интерфейс показывает затронутые маршруты; после подтверждения ссылки на нее удаляются из миксов.

## Маршруты BlackHole

- Создание требует установленного и доступного устройства BlackHole. Пользователь выбирает конкретный экземпляр по UID и его выходные каналы из обнаруженного списка.
- Маршрут имеет редактируемое имя, собственный микс и общую громкость. Выбранные каналы сохраняются по индексам в пределах данного устройства.
- Для стереомикса пользователь может выбрать два различных канала. Для моно маршрута допускается один канал. Другие схемы каналов проектируются отдельно после проверки прототипа.
- Пересекающиеся каналы двух активных маршрутов одного устройства запрещены, чтобы миксы не перезаписывали друг друга.
- Если для устройства BlackHole настроен микс в строке реального выхода, он занимает его выходные каналы; маршрут BlackHole с пересечением каналов также запрещен. Перед реализацией проверяем, можно ли назначить этому базовому миксу подмножество каналов; до такой проверки он резервирует все выходные каналы устройства.
- Прототип `prototypes/channel-routing/` подтвердил запись в произвольный один канал или два различных канала BlackHole 64ch через полный многоканальный клиентский буфер. Базовый микс BlackHole в первой версии продолжает резервировать все каналы, пока выбор его подмножества не описан как отдельное действие пользователя.
- При отсутствии драйвера, изменении числа каналов или отключении устройства маршрут сохраняется как недоступный и не запускается. Интерфейс предлагает выбрать доступные каналы или устройство.
- Sound Mixer не устанавливает и не обновляет BlackHole автоматически.

## Ползунки

- Общая громкость реализована программным усилением результата микса: 0 % означает тишину, 100 % означает единичный коэффициент без усиления.
- Движение ползунка применяет значение без перезапуска аудиотракта и отражается в интерфейсе после подтверждения нативной частью.
- При аппаратном регуляторе громкости устройства системная громкость остается независимой от этого ползунка.
