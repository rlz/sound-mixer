What it does

Audio sources, mixes, and outputs

↗

Choose audio sources

Use physical input devices, eligible running applications, and internal virtual buses as mix sources.

≋

Set levels per mix

Balance sources independently for each destination. View signal meters and route channels where supported.

◎

Reuse internal buses

Create a virtual bus inside the app and add its mix to another destination. It is not a macOS system device.

System requirements

For macOS 15 and later

  • ✓A Mac running macOS 15 or later.
  • ✓Microphone permission for physical input capture.
  • ✓System Audio Recording permission for application audio capture and some device meters.
  • ✓No custom audio driver is required for the app's internal virtual buses.

Capture depends on macOS

Only eligible application audio exposed by macOS can be captured. Available device controls and channel layouts vary by hardware. Rlz Sound Mixer does not record audio to files or change the macOS default output.
